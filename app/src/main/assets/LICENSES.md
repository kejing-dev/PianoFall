# Third-party material in Piano Fall

## Piano samples — assets/piano/*.ogg
Salamander Grand Piano V3 (Yamaha C5), by Alexander Holm. License: CC-BY 3.0
(http://creativecommons.org/licenses/by/3.0/). 30 samples, one every minor third A0 - C8, one velocity layer,
as redistributed by the Tone.js audio collection (https://github.com/Tonejs/audio/tree/master/salamander, the
folder's README carries the author's licence text, checked 2026-10-27). Unmodified.

## Fonts — res/font
Noto Sans, Noto Sans SC (subset): SIL Open Font License 1.1 (third_party/).

## Songs
All works are in the public domain (composers dead more than 70 years, or traditional tunes). The note data was
typed in for this app; left hands marked "left hand by this app" and simplified arrangements are this app's own
(see the About page and the gate C list).
